about

sata-emu runs ps5 games on pc. guest code runs natively on the cpu, the system libraries are reimplemented (hle) and the gpu side goes through vulkan.

it's a side project and it's early. most stuff is broken. updates go on github and x.

x86-64 native hle kernel vulkan 1.3 windows 10/11

changelog

v0.4.2-dev nov 22 2026 pre-release

internal preview build, not available for download.

  • story mode loads now and the first mission can be played start to finish
  • fixed the gpu device lost crash when entering story mode cutscenes
  • vulkan: fixed swapchain recreation on window resize
  • shader recompiler: added V_DOT2_F32_F16 and V_PERMLANE16_B32 (slow path)
  • pfs: deferred loading for flagged chunks
  • audio: 8ch to 2ch downmix
  • input: dualsense, dualshock 4 and xbox controllers work over usb and bluetooth
known issues
  • crashes after the first mission ends (save / transition to free roam)
  • 20-30 fps, stutters while shaders compile
  • some cutscenes have missing textures or flicker
  • no keyboard and mouse yet
  • uses a lot of ram (~10 gb)
